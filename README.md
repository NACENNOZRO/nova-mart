# Nova Mart

A single-file ecommerce interface built with HTML, CSS and JavaScript. Includes animated product listings, category filtering and shopping cart interactions.

## Run locally

Open `index.html` in a browser, or serve this directory:

```sh
python3 -m http.server 8080
```

Visit `http://localhost:8080`.

## Scope

This is a frontend demonstration. It does not provide a production payment gateway, order fulfillment or customer account backend. Google Fonts and external product images require internet access.

## Source

The original saved HTML is preserved as `index.html`.
